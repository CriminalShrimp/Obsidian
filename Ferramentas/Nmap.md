Usado para identificar dispositivos, portas e serviços na redes, além de descobrir vulnerabilidades na mesma o Nmap é usado para para realizar o mapeamento de redes de forma simples e rápida, ou de forma complexa e detalhada. Existe para diversos sistemas operacionais, possuindo uma interface para seu uso, porém sendo mais usada via [[Abreviações#CLI = **C**ommand **L**ine **I**nterface é onde são realizados os comandos do sistema.|cli]].
